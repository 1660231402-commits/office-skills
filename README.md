# 办公类 skill · 生活复盘自动化（life-report）

一个 ZCode skill：每天记录发生的事情（支持文字 / 文件 / 语音），定时邮件提醒与补发检查，自动生成带分析与名人名言鼓励的**日报 / 周报 / 月报 / 半年报 / 年报**（黑白报刊风 HTML）并发送到邮箱。

## 功能一览

- **三种记录方式**：打字、读文件（txt / md / docx / 截图照片）、语音（Win+H 实时输入；wav 离线转写）
- **补发与修改**：忘记的日子随时补发，写错的内容精准更正
- **定时自动化**：每天 8 / 10 / 20 / 22 点触发 —— 20/22 点记录提醒、10 点补发检查、8 点生成报告（周报逢周一、月报逢 1 日、半年报逢 1月1日/7月1日、年报逢 1月1日）
- **报告内容**：重点事件记录、好事情、坏事情、这段时间的分析与改善建议、名人名言鼓励；HTML 正文 + 附件，全部在周期结束后第二天内送达
- **零依赖**：Windows 自带 PowerShell 5.1 即可运行，无需安装任何东西

## 安装

1. 把 `.agents/skills/life-report/` 放入你的工作区（ZCode 会自动发现 `.agents/skills/` 下的 skill）
2. 复制 `config.example.json` 为 `config.json`，填入你的邮箱与 SMTP 授权码（**此文件已被 .gitignore 排除，不会被提交**）
3. 对 ZCode 说「测试邮箱」验证

授权码获取：QQ 邮箱网页版 → 设置 → 账户 → 开启 POP3/IMAP/SMTP 服务 → 生成授权码（163 / Gmail / Outlook 的设置见 skill 内 README）。

## 使用

```
记录事件：今天……          # 打字记录（或 Win+H 语音输入）
补发 9 月 10 日的事件：……  # 补发
修改 9 月 10 日的记录：……  # 更正
生成今天的日报             # 手动出报告
```

## 目录结构

```
.agents/skills/life-report/
├── SKILL.md               # ZCode 执行逻辑
├── README.md              # 使用指南
├── config.example.json    # 邮箱配置模板（真实 config.json 不入库）
├── scripts/               # PowerShell 脚本：发邮件 / 检查补发 / 汇总数据 / 选名言 / 语音转写 / 读 docx
├── assets/                # 报告模板（黑白报刊风）+ 名言库
└── data/                  # 你的事件记录与已发送状态（不入库）
```
