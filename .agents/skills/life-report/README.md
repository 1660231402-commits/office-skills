# 生活复盘助手（life-report）

每天记录发生的事情，自动收到邮件提醒；日报、周报、月报、半年报、年报自动生成并发到你的邮箱 —— 每份报告都包含**重点事件记录、好事情、坏事情、这段时间的分析与改善建议、名人名言鼓励**，格式为 HTML，邮件正文可直接查看，附件可下载后用浏览器打开。

## 第一次使用（必做，约 2 分钟）

1. 打开 [config.json](.agents/skills/life-report/config.json)，填入你的邮箱和 SMTP **授权码**（不是登录密码）：

   ```json
   {
     "smtp": {
       "host": "smtp.qq.com",
       "port": 465,
       "ssl": true,
       "starttls": false,
       "username": "你的邮箱@qq.com",
       "password": "你的SMTP授权码",
       "sender_name": "生活复盘助手"
     },
     "to": ["接收报告的邮箱（一般填自己）"]
   }
   ```

2. 获取授权码：
   - **QQ 邮箱**：网页版 → 设置 → 账户 → 开启「POP3/IMAP/SMTP 服务」→ 生成授权码
   - **163 邮箱**：设置 → POP3/SMTP/IMAP → 开启服务 → 新增授权密码（host 改为 `smtp.163.com`）
   - **Gmail**：开启两步验证后生成应用专用密码（host 改为 `smtp.gmail.com`）
   - **Outlook**：host 改为 `smtp.office365.com`，port 587，`ssl: false`，`starttls: true`

3. 发一封测试邮件确认配置正确（在 ZCode 中对我说「测试邮箱」，或手动执行）：

   ```
   cd /d D:\办公类skill\.agents\skills\life-report
   powershell -NoProfile -ExecutionPolicy Bypass -File scripts\send-mail.ps1 -mode test
   ```

## 每天怎么用（支持文字 / 文件 / 语音）

- **打字记录**：对我说「记录事件：今天……」，随手说什么都行，我会整理成 重点事件 / 好事情 / 坏事情 存档。
- **语音记录（推荐）**：在对话框按 **Win + H**（Windows 语音输入）直接说话，说完我自动整理；也可以把录音文件（wav 格式）路径发我或拖进来，我会离线转写后先请你确认再存档。
- **文件记录**：把日记/笔记文件（txt / md / docx / 截图照片）路径发我，说「把这个记进去」，我提取要点后存档。
- **补发**：忘了某天？说「补发 9 月 10 日的事件：……」，随时可补。
- **修改**：记错了？说「修改 9 月 10 日的记录：把跑步改成 5 公里」，我会精准更正，不动其他内容。
- **手动出报告**：说「生成今天的日报」「出上周的周报」等。

## 自动化时间表（已配置好）

| 时间 | 自动做什么 |
|---|---|
| 每天 20:00 | 邮件提醒记录今天的事件 |
| 每天 22:00 | 最后一次提醒 |
| 次日 08:00 | 发送**昨天**的日报（无记录则跳过）；逢周一同时发上周周报；逢每月 1 日同时发上月月报；逢 1月1日 / 7月1日 同时发半年报与年报 |
| 次日 10:00 | 检查昨天是否补发，缺失才发提醒邮件 |

所有报告都在周期结束后第二天内送达；重复触发不会重发同一份报告。

## 文件说明

```
.agents/skills/life-report/
├── config.json            ← 邮箱配置（你要填的地方）
├── SKILL.md               ← ZCode 执行逻辑
├── scripts/               ← PowerShell 脚本（发邮件/检查/汇总/选名言）
├── assets/                ← 报告模板 + 名言库
└── data/
    ├── events/            ← 你的每日事件记录（YYYY-MM-DD.md）
    ├── reports/           ← 生成过的报告 HTML
    └── state.json         ← 已发送记录
```

## 常见问题

- **没收到邮件？** 先跑上面的测试命令看报错：授权码错、端口/SSL 不匹配、收件人地址错是最常见原因；如果提示"邮箱尚未配置"，回到第一步填 config.json。
- **语音识别不准？** 离线转写用的是 Windows 自带中文引擎，准确度有限（所以转写后会先请你确认）。最推荐 **Win+H 实时语音输入** 或手机输入法语音转文字。录音文件目前仅支持 wav（PCM）格式，微信/录音机的 m4a、amr 需先转格式。
- **定时任务没执行？** 检查自动化任务列表是否还在（对话里说"查看定时任务"），并确认当时电脑处于开机状态。定时任务每天 8 / 10 / 20 / 22 点触发一次，按时间点分派任务。
- **想改提醒时间或暂停？** 直接告诉我，比如「把提醒改到 21:00」「暂停周报」。
- **想重发某期报告？** 告诉我日期和报告类型，我会清掉对应的已发送记录并重新生成。
- **数据在哪？** 全部在本机 `data\` 目录，事件记录是纯文本 Markdown，随时可以备份。
